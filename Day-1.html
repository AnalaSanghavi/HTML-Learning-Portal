1. WHAT IS THE INTERNET?

The Internet is a global network connecting computers and devices worldwide to share information.

2. WHAT IS A WEB?

The Web is a collection of websites and web pages accessed through the Internet.

3. WHAT IS A WEBSITE?

A website is a collection of related web pages that are accessed through a domain name.

Examples of Website Pages:

  • Home
  • About
  • Contact

4. WHAT IS A WEB PAGE?

A web page is a single page on the Web that can contain text, images, videos and links. It has a URL.

A web page is accessed through a unique address called a URL (Uniform Resource Locator).

5. WHAT IS A WEB BROWSER?

A web browser is a software application that allows users to access and view web pages on the Internet.

Examples of web browsers:

  • Google Chrome
  • Mozilla Firefox
  • Safari
  • Microsoft Edge

6. WHAT IS A WEB SERVER?

A web server is a computer that stores and delivers web pages to users over the Internet.

7. WHAT IS A WEB APPLICATION?

A web application is a software application that runs on a web server and is accessed through a web browser.

KEY TAKEAWAYS

  • Internet connects devices.
  • The Web provides pages and websites.
  • Browsers help us access web content.
  • Web applications let us interact and complete tasks.
