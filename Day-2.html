Day 2: HTML TAGS

Building the Structure of Web Pages

1. WHAT IS AN HTML?

  • It is used to structure and display the content on web pages.
  • HTML stands for HyperText Markup Language.
  • It is a markup language.

2. WHAT IS HYPERTEXT AND MARKUP?

HyperText

  • "Hyper" means a link.
  • Hypertext is clickable content that can take us to another page, image, video or resource.

Markup

  • "Markup" means tags are used to mark or structure the content.
  • HTML uses tags to tell the browser how to display the content.

3. HISTORY OF HTML

HTML was created by Tim Berners-Lee in 1991. It has evolved over the years with different versions and standards.

Year HTML Version Description
1991 HTML 1.0 First version of HTML
1995 HTML 2.0 Added support for forms and images
1997 HTML 3.2 Introduced tables and applets
1999 HTML 4.01 Introduced CSS and improved accessibility
2014 HTML5 Current version with multimedia support and new APIs

4. HTML TAGS

Paired Tags

  • Paired tags have an opening tag and a closing tag.
  • Example:

Opening Tag: <p>

Closing Tag: </p>

Self-Closing Tags / Unpaired Tags

  • Some tags do not have a closing tag.
  • Example:

<br>

Line break tag

5. BASIC HTML STRUCTURE

<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Page Title</title>
    </head>
    <body>
        <h1>Hi,Welcome to HTML</h1>
    </body>
</html>

Explanation:

  • <!DOCTYPE html> - Declares the document type.
  • <html> - This is the root element.
  • <head> - This Contains meta information (such as title).
  • <body> - This contains the visible content of the web page.

6. HTML ELEMENTS

An HTML element consists of an opening tag, content, and a closing tag.

Example:

<p>This is a paragraph.</p>

  • Opening tag: <p>
  • Content: This is a paragraph.
  • Closing tag: </p>

  • The <p> tag defines a paragraph.
  • This tag is used to create paragraphs of text on the web page.
